# UI Frameworks

## Why use UI Frameworks?

UI Frameworks is an amazing tool for developers. With their ease of use and plethora of built in components, UI Frameworks makes website design simpler and responsive. They allows development on computers, but ever more important, mobile. Navigation bars and buttons are just some of the built in components that make website building faster. Creating these from scratch with just HTML and CSS can make code longer unnededly.

## Using Bootstrap 5
<img src="/img/bootstrap-logo.jpeg" alt="TypeScript Logo" width="180" />

A great example of a well polished UI Framework. It has all the components you would need to create a well functioning website. Through this class we have used Bootstrap 5 to create websites that mimicked real websites found online. The ease of use due to the built in components allowed for creating a responsive navigation bar with all the buttons and dropdown menus that a website would need. Using the components of Container, Row, and Column to organize the page made things so much more efficient.

## Overview
Developers looking to create responsive and well fleshed out websites should look to UI Frameworks. With their built in tools, they allow for organized and efficient code. Bootstrap 5 is a great tool in the hands of developers of all calibers and I will continue to use it in the future for projects.
